# station-upgrades Specification

## Purpose

为单机餐厅提供沿既有跨关装修流程安装的原工位升级，以有限的加工耗时改善形成经营选择，并保留工位身份、占地、内容和已开始作业；保存恢复时准确保留等级，避免重复安装或重算旧加工。

## Requirements

### Requirement: 有限原工位升级候选
Solo 与已接入升级的合作非终关装修 SHALL 可提供匹配现有加工工位的同占地单级升级，候选明确目标工位和预期等级。已升级、目标不存在或能力不符不得成为合法选择。

#### Scenario: 无可升级目标
- **WHEN** 餐厅没有符合该奖励的未升级工位
- **THEN** 不提供不可兑现的升级候选，其他合法奖励仍按原流程选择

### Requirement: 升级保留工位与物品身份
升级 MUST 在合法继续的安装阶段预检后一次提交，保留原工位、位置、容器、物品和已开始作业；失败无部分变更，重复请求不得重复升级。

#### Scenario: 选择后目标不满足安装条件
- **WHEN** 安装时目标身份或预期等级不再匹配
- **THEN** 拒绝安装，原工位、物品、等级和关卡保持一致，显示可处理的原因

### Requirement: 升级仅影响新作业
工位升级 MUST 仅改变随后启动的匹配作业；与有效 Buff 共同作用时从基础耗时乘各比例，统一向上取整且至少一个业务 Tick。旧作业保留原冻结参数。

#### Scenario: 升级时工位已有作业
- **WHEN** 同一工位在升级前后分别开始作业
- **THEN** 旧作业时长保持，新作业使用新等级及当时 Buff，不因计算顺序多次取整

### Requirement: 升级持久恢复不再次安装
成功检查点 MUST 保存工位升级事实和作业冻结参数；旧有效格式以未升级状态只读适配，恢复不重复发奖励、应用比例或安装升级。

#### Scenario: 保存升级工位后重入
- **WHEN** 玩家保存升级后的餐厅并从该检查点恢复
- **THEN** 工位等级、实物和作业参数与已保存结果一致，升级次数不增加

### Requirement: 首版模式范围明确
升级候选 MUST 向 Solo 及已接入本能力的合作模式开放。合作只有 Host 当前本地合法成员可选择和继续，远端只读；尚未接入持久化的合作升级仅属于本轮内存餐厅。

#### Scenario: 合作生成装修候选
- **WHEN** Host 创建本轮联机装修候选
- **THEN** 候选只包含当前可兑现的新增或单级升级，远端直接提交选择须拒绝且无改动

### Requirement: 合作升级投影与目标一致

合作升级 MUST 向双方提供当前候选、目标工位、预期等级与已提交结果的独立值投影，恢复成员取得当前事实，不重演历史选择。

#### Scenario: 升级后原成员恢复
- **WHEN** Host 已完成升级，原成员随后合法恢复
- **THEN** 恢复端读取同一等级和工位身份，不新增升级或重算作业

### Requirement: 已交付加工工位可单级升级
灶台、榨汁机、煎台、搅拌机、磨豆机、咖啡机和蒸汽机 SHALL 沿既有关间装修提供同占地单级升级，设备能力须匹配实际加工类别；升级只改变后续该设备上的匹配作业耗时。原工位身份、载具、内容、旧作业和合作权限保持。

#### Scenario: 升级具有两种加工模式的蒸汽机
- **WHEN** 合法选择并安装蒸汽机升级
- **THEN** 新热奶和打泡均使用升级比例，已开始作业保持原冻结耗时

#### Scenario: 升级后保存并恢复
- **WHEN** 成功检查点或合作结果领取后恢复该餐厅
- **THEN** 读取同一等级和物资状态，不重发奖励或再次缩短已保存作业
