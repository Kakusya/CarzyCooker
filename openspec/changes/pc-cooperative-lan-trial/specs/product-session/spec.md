# Spec Delta

## MODIFIED Requirements

### Requirement: 监听与连接存活

产品 SHALL 默认仅连接本机 loopback；显式 LAN 模式可使用合法私网 IPv4 的明确地址。Host 监听必须报告实际绑定的非零 endpoint，端口冲突明确失败；不将配置端口 0 或 Pipeline 工具端口交给 Client，不扫描网络或自动修改全局防火墙。远端加入成功后须解除接入验证超时并维持有界心跳及既有空闲断线检查，本地消息通道无需网络心跳。

#### Scenario: 动态监听端口
- **WHEN** Host 配置以端口 0 启动
- **THEN** 报告实际绑定地址和非零端口，另一端显式使用该结果；不猜测或扫描替代端口

#### Scenario: 连接保持空闲
- **WHEN** 已加入的远端连接没有业务命令但双方正常运行
- **THEN** 心跳使连接正常保持；对端失联时有限时间内结束等待并报告失联，不无限积累请求

#### Scenario: 局域网连接失败
- **WHEN** 显式 LAN 目标不可达或被系统阻止
- **THEN** 有限等待后报告连接失败，保留实际原因，不自动修改网络环境
