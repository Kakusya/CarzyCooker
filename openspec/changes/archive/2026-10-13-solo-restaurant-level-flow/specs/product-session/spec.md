# Spec Delta

## ADDED Requirements

### Requirement: 单机餐厅模式的关卡隔离

正式单机餐厅模式 MUST 在持续世界身份之外校验当前 Level 身份与代次；角色只属于当前关，结束角色前按唯一位置规则保留手持实物。关卡切换后旧动作和旧投影不得写入新关，厨房的未变实例、内容与剩余份数不得因关卡代次变化重建。本要求不把旧临时样机声明成持久餐厅。

#### Scenario: 世界相同而关卡已经更换
- **WHEN** 同一家餐厅换关后收到上一关的动作或快照
- **THEN** 按关卡身份拒绝，不因世界仍相同便应用旧得分、认领或动作

### Requirement: 单机餐厅沿用本地裁决入口

单机餐厅 MUST 使用既有产品本地加入、独立客户端及共同裁决入口，不创建网络监听。关卡控制、布局、前厅与 buff 请求须遵守相同绑定、上下文、接收／最终结果和消息所有权规则；控制消息泵在暂停期间仍运行，不能让暂停造成无法恢复。

#### Scenario: 暂停后经本地消息恢复
- **WHEN** 本关已暂停，玩家从有效本地客户端请求恢复
- **THEN** 请求经过真实本地入口并取得结果，无需网络、自报内部地址或直接修改 Host 状态
