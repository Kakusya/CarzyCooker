# Spec Delta

## MODIFIED Requirements

### Requirement: 经营关键变化提供可关闭视觉提醒

界面 SHALL 对本轮新发生的到货、加工完成和订单进入临期提供有限视觉提醒，能显式查看仍有效的原目标；各类提醒可独立关闭并本机保存。默认开启，临期阈值默认5个业务秒且可调整，不改变原订单期限。提醒不得自动移动、取货、盛装、绑定、交付或暂停。加工完成可与经营声画反馈共享一次完成音效，音量/静音由独立声音设置控制；视觉类别关闭不替代声音开关。到货和临期保持仅视觉提醒。

#### Scenario: 同一步多个加工和到货结果

- **WHEN** 同一业务步内两项真实加工完成且一件货物到达
- **THEN** 界面能查看三项独立事实，各只提醒一次；选择查看不发业务动作，关闭对应类别后不再产生该类新提醒

#### Scenario: 完工视觉和音频同时启用

- **WHEN** 一个新的加工完成同时满足视觉提醒和音效触发条件
- **THEN** 该事实只产生一次完成音效；关闭声音仍能看到启用的视觉提醒，到货和临期不新增声音
