# Spec Delta

## ADDED Requirements

### Requirement: 第一章首关提供可跳过的当前一步

Solo 第一章首关 SHALL 自动显示当前首单目标及一步可理解说明，衔接准备、必要加成、可选备料、开店、真实接待询单、制作盛装、交付与收尾。玩家可跳过或重看；提示不得新增开店门槛、自动暂停或代交动作，不保存永久教学进度。其他菜单保留原菜谱能力，合作不强制开启此教程。

#### Scenario: 新开第一章与跳过

- **WHEN** 玩家新开「家常开张」首关并跳过提示
- **THEN** 原准备和开店功能可正常使用，世界不被修改；重新打开后按当前事实说明，无须重做已备料

#### Scenario: 完成首单

- **WHEN** 玩家通过原操作实际交付一张有效汤单
- **THEN** 提示显示真实首单完成并可关闭或重看，接受请求但尚未执行时不能提前完成教学目标

### Requirement: 首单定位指向当前有效物件

首单提示 SHALL 为可定位的材料、容器、设备或顾客提供只读查看与高亮，并按当前可用实物、加工锁定和配方缺口重算。缺料时说明真实补货/清理途径，不能生成物品或指向不存在的对象；查看只改变显示和必要镜头位置。

#### Scenario: 已备料或材料缺失

- **WHEN** 已有合法半成品或所需原料尚未到货
- **THEN** 前者跳过已满足的制作建议，后者说明缺口且不把在途物资当作可取物；点击查看不增加业务命令

### Requirement: 首单显示与原关和订单身份一致

提示 MUST 在目标消失、订单过期、关卡或绑定变化后撤销失效定位，保持暂停和当前权限；HUD重开不重复订阅或恢复旧目标。选择新的有效订单须是明确阅读选择，不能因提示改变饮品绑定或自动交付。

#### Scenario: 订单过期后重开提示

- **WHEN** 被查看订单已过期，玩家关闭重开提示后触发旧定位回调
- **THEN** 旧回调不影响当前目标，新的说明来自当前事实；一次随后执行的原合法动作只提交一次
