# Spec Delta

## Purpose

定义本地与远端玩家共用的权威命令、业务时钟、提交结果和状态同步边界，避免传输成功、动画完成或观察事件变成另一份业务权威。本文捕获未来业务契约，ET 会话原型和底座机制不能作为其已实现证明。

## ADDED Requirements

### Requirement: 本地和远端进入共同权威

所有玩家意图 MUST 经过可信身份绑定、共同验证及权威提交。本地玩家使用进程内消息，远端使用传输适配入口；UI、网络回调和表现不得直接修改玩法状态，不能因为本地身份跳过验证。

#### Scenario: 两名玩家争抢同一物品
- **WHEN** Host 本地玩家与远端玩家提交拾取同一物品的意图
- **THEN** 进入同一规则与仲裁，只有合法胜者取得物品，不因房主身份优先或复制物品

### Requirement: 固定业务时钟与唯一写入权威

Host MUST 在固定业务 Tick 校验、裁决和提交烹饪、顾客、伙伴与供应状态；渲染帧、墙钟、动画回调及网络接收仅提供输入或表现。网络输入在入队时分配原子接收序号，不能与历史单机排序规则静默混用。

#### Scenario: 动画先结束而加工时间尚未到
- **WHEN** 表现动画结束，但权威业务时钟尚未满足加工完成条件
- **THEN** 加工保持未完成，不产生可消费结果

### Requirement: 命令完整验证和代际隔离

命令 MUST 核对身份、资格、Match／Level／连接代次、距离、容量、占用、版本和重复；消息须验证协议版本、种类、必填字段、枚举及大小限制。旧代次或未知协议不得静默执行。

#### Scenario: 换关后迟到的投料
- **WHEN** 上一 Level 或旧连接的命令在当前世界到达
- **THEN** 明确拒绝，不扣料、不改变当前加工，也不自动解释成当前关指令

### Requirement: 幂等与命令载荷冲突

同一业务命令 ID 和同载荷重试 MUST 返回既有处理事实，不重复扣料、生成物品或结算；同 ID 不同载荷须明确冲突，不能按新指令执行。业务 ID 与传输 RPC 编号不能混为一体。

#### Scenario: 成功盛装后重试
- **WHEN** 同一盛装业务指令被重复送达
- **THEN** 返回既有结果，不再减少一份源批次或增加一份成品

#### Scenario: 重用命令编号修改目标
- **WHEN** 已处理命令的同 ID 请求携带另一目标
- **THEN** 返回冲突，不执行第二次动作

### Requirement: 原子动作与提交事实

动作 MUST 在完整预检后原子提交，先提交状态再发布事件。Command、准入、最终处理结果、已提交事件、完整快照、传输 ACK 与业务 Ready 须区分。观察者异常不回滚已提交动作；固定步后续失败保留已提交效果及 Executed 终态，但本帧 Tick 不推进。

#### Scenario: 已提交动作后观察者异常
- **WHEN** 一次合法拾取已提交，后续监听器或固定步失败
- **THEN** 保留拾取效果与命令终态，不能再次执行或以整帧回滚抹除它；固定步失败不推进本帧 Tick

### Requirement: 完整快照与客户端只读投影

首阶段系统 MUST 以权威完整状态快照同步，Client 被动显示，不承担玩法写权限或预测回滚。客户端只应用当前 Match、Level 及有效绑定的适用版本，不能用私有缓存替换 Host 状态。网络发送成功不表示对方已应用状态。

#### Scenario: 同步完成与 Ready 区分
- **WHEN** Host 已发送完整状态但 Client 尚未验证并安装
- **THEN** 不仅凭发送完成或传输 ACK 宣告业务 Ready

### Requirement: 暂停与连接控制分离

暂停和恢复 MUST 由 Host 控制；暂停停止统一业务时钟，包括加工、顾客、伙伴和到货，但允许连接控制及完整状态同步。Client 重连不得自动恢复营业。暂停时尚未执行队列的取消／保留策略另待裁决。

#### Scenario: 暂停期间重新连接
- **WHEN** Client 在 Host 暂停时恢复连接并同步状态
- **THEN** 仍保持暂停，业务进度与在途货物到货计时不增长

### Requirement: 业务收尾先于资源释放

正常结束 MUST 在关闭连接和释放 owner 前完成适用业务收尾及稳定离线凭证导出；Dispose 不代替成功结算或存档。退出可重复调用，异步继续前核对生命周期、代次和取消；单连接退出不能停止其他玩家共用的消息资源。

#### Scenario: 单连接退出且回复迟到
- **WHEN** 一个成员连接退出后旧回复到达
- **THEN** 不写入新绑定或下一轮状态，其他成员仍可通信，已提交结果保持
