# Spec Delta

## Purpose

定义固定伙伴的岗位、关内成长以及玩家可选接手工作，使自动服务减轻基础负担并保留自然协作。本文捕获明确确认及授权补足规则，伙伴最终人数、名字、性格和额外能力保持候选，不代表当前已有伙伴系统。

## ADDED Requirements

### Requirement: 固定身份岗位与自动工作

伙伴 MUST 保持固定身份和岗位，按工作创建顺序自动执行适用工作；不能作为随意招募替换的通用劳动力。基础规则不引入岗位微操、工资、疲劳、饥饿或情绪维护，最终人数不得由原型人数推导。

#### Scenario: 前厅出现多个待办工作
- **WHEN** 固定伙伴可领取多个适用且未被占用的工作
- **THEN** 按创建顺序领取合法工作，玩家无需先下达逐项岗位指令

### Requirement: 成长只计算实际伙伴完成

成长 MUST 以本小关伙伴实际完成的询问或洗碗工作为准，完成计数是唯一可写事实，能力状态由其推导。玩家完成、取消、尝试领取或重复完成通知不能增加伙伴成长；下一关及适用失败重置，同关技术恢复保留。

#### Scenario: 玩家代为询问顾客
- **WHEN** 玩家合法完成一项询问工作
- **THEN** 正常生成适用订单，但伙伴完成次数不增加

### Requirement: 第三次完成解锁洗碗加速

伙伴 MUST 在实际完成第三项适用工作后解锁本关洗碗加速，加速耗时为 `max(1, ceil(baseWashTicks / 2))`。任务领取时冻结本次耗时，不能追溯缩短已经领取的工作；同 Tick 后续领取可使用刚解锁的能力。

#### Scenario: 第三项工作结束后领取洗碗
- **WHEN** 伙伴提交第三项完成，并在同 Tick 后续领取新洗碗工作
- **THEN** 新工作冻结加速耗时，已在进行中的其他工作仍保持原耗时

### Requirement: 人工接手与单执行者

玩家 MUST 能可选认领适用前厅工作，同一工作只允许一个执行者；停止或离开保留进度并释放认领，伙伴可以继续。人工不是默认强制逐桌服务，也不建立第二份工作状态。

#### Scenario: 玩家中途离开洗碗工作
- **WHEN** 玩家停止持续参与，工作还未完成
- **THEN** 释放执行占用并保留已做进度，伙伴可从原进度继续，不重新开一份工作

### Requirement: 关间重置和收口模式

伙伴 MUST 在新 Level 重置关内成长和临时工作认领，不把旧任务进行中状态直接搬到下一关。必要前厅工作按当前模式收口，人工模式不得强行完成，历史自动模式不扩大其适用范围。

#### Scenario: 伙伴带加速完成当前小关
- **WHEN** 进入下一小关
- **THEN** 固定身份及岗位保留，完成次数和本关加速清零，旧工作认领不继续生效
