# Spec Delta

## ADDED Requirements

### Requirement: 厨房物品查找入口可访问

系统 SHALL 提供以下入口行为：按物品名称／类别查看当前实物位置、外层宿主和状态，区分手持、台面、容器内、地面、脏净池及加工锁定；选择结果仅查看／高亮当前宿主。

#### Scenario: 厨房物品查找入口的正常使用
- **WHEN** 查找被队友拿走的容器内原料和落地餐具
- **THEN** 结果指向实际持物者或宿主格并解释状态，同一实例不重复计数，点击只查看

### Requirement: 厨房物品查找入口保持事实与操作边界

系统 MUST 遵守以下边界：物品以唯一实例计数，容器内容与外壳分开，不将锁定输入或在途货冒充可取库存；不自动拾取、不给远距离操作权，地图高亮不移动角色。

#### Scenario: 厨房物品查找入口的取消或状态变化
- **WHEN** 查找后物品被消费、加工锁定或随队友断线落地
- **THEN** 旧位置不继续显示为可取，信息跟随当前事实且不会远程拿物

#### Scenario: 厨房物品查找入口关闭重开与旧回调
- **WHEN** 玩家关闭并重开本入口，随后旧页面回调或迟到结果到达
- **THEN** 页面只作用于当前有效上下文，原操作不因重开重复提交，旧结果不覆盖新选择，原合法入口仍可使用
