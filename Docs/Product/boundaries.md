# 产品边界

只约束未来设计，不描述当前代码能力。状态沿用 [设计](design.md)、[候选目录](catalog.md)。

- Host 是世界权威，不自动是存档 Owner；本地玩家也走统一裁决。
- 运行世界、持久进度和领取凭证分开，小关成功不自动写所有人文件，不自动合并分支。
- PC/Android 协作和玩家数据生态隔离，共享逻辑不等于互联/互换存档。
- 大关持续同一家餐厅，小关自然结束，未满足订单计 0，不倒扣、不阻止继续、不生成正常失败界面。
- 固定伙伴长期陪伴、关内成长，基础范围无工资/疲劳/饥饿/心情维护负担。
- 普通手槽/台面一格一物，容器内容随容器移动；物品不重复占位、不成环。
- 制作、暂存、绑定、交付不同，分装守恒；拒绝不留下半次扣料/搬运。
- 基础无精细刀工、翻面、拉花、封盖小游戏，不自动加入火灾/烧焦/故障/保质/污渍。
- 供应申请、到货、接收、厨房实物分开；收尾不新申请，已批准货物照常处理；布局仅准备态修改。
- 主机迁移、公网/中继/NAT/大厅/观战/多房间、预测/回滚/Delta 是后续候选，不隐含加入首阶段。

旧工程测试框架、端口工具、禁用传输和开发门禁不迁成新规则。工具审批、SHA 与 JSON 证据禁令属于 [当前协作入口](../../AGENTS.md)；未来协议和存档数据格式另由契约定义。
