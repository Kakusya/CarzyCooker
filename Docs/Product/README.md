## 四种状态

- 已确认：原资料标记「明确确认」的产品共识；不声称重新检索到每轮原话。
- 授权补足：历史授权细化设计；旧工程实施授权不延续到本项目。
- 候选：目录/方案/未平衡数值，不是逐条批准或已实现。
- 待裁决：来源冲突或未知项，实施前取得决定，助手不代定。

正式文档仅用本项目有效引用与原件章节。原件内历史路径、失效链接、测试入口和工作树记录不参与现行路由；保留原件不恢复旧工具、任务或专属限制。
